# Data quality report

Generated by `scripts/01_preprocess.R`. Row counts and percentages are computed from the raw files each run.

## What was wrong and what was done

| Source | Issue found | Fix |
|---|---|---|
| Airport lookup | 191 of 342 rows had blank name, city and state (56%). Only 36% of flights had a named origin, so the top routes showed raw IDs. | Rebuilt from the complete BTS airport-ID table (all 342 IDs found; the 151 rows that were filled agree 100%). Split into city, state, state name, census region. Added IATA code and coordinates (OurAirports, matched by name and state, 10 manual overrides). Dropped 4 redundant columns (sequence ID, city-market ID, source URL, status). |
| On-time reporting | 544,003 rows but only 5,812 distinct origin/destination pairs (98.9% exact duplicates). Six ID columns, four of them redundant. Undated. | Aggregated to one row per directed route with a flight-record count. Added IATA route labels, an undirected pair label (so ORD-LGA and LGA-ORD combine) and a has-return flag. |
| Baggage complaints | Date stored as text `MM/YYYY`; Month and Year duplicate it; header carried a byte-order mark; rates not provided. | Parsed to a real month-start date, dropped the duplicate columns, renamed to plain English. Rates are computed in DAX from the totals (never averaged). |
| Survey | Unnamed index column; 83 blank arrival delays (0.3%); 2,113 respondents (8.1%) with a rating of 0, which means *not applicable*, not a score; inconsistent label case (`disloyal` vs `Loyal`). | Index dropped. Zeros set to blank. Blank arrival delays imputed from departure delay with a linear fit (r = 0.965) and flagged in `ArrivalDelayImputed`. Labels standardised. Added age, distance and delay bands (with sort keys), a service score, a satisfied flag. |
| Survey (model) | 14 rating columns are awkward to chart together. | Added `fact_ratings` (long format, N/A rows excluded) so one chart can compare all factors. |
| Date | No calendar table. | Daily calendar 2004-2010 with year, quarter, month, season. |
